# Trabajo paralelo

El proyecto es individual; la ejecución se separó por área mediante subagentes.

| Agente | Alcance | Entrega |
| --- | --- | --- |
| database | Prisma, índices y semilla | contrato de datos |
| backend | rutas, reglas y pruebas | API `/api` |
| frontend | UI, tipos y pruebas | experiencia integrada |

Los hooks protegen secretos y cambios destructivos. El skill `$punto-barrio` preserva invariantes y trazabilidad.
