# Obsidian Punto Barrio

Vault de conocimiento del sistema Punto Barrio. Incluye arquitectura, documentación de ocho módulos, trazabilidad SDD, operación en Render, decisiones y evidencia de calidad.

## Uso

1. Abrir esta carpeta como vault en Obsidian.
2. Activar **CSS snippets** si Obsidian lo solicita.
3. Comenzar en `Bienvenido.md` o en `00 Inicio/Mapa Maestro.canvas`.

La configuración versionada asigna colores por módulo tanto en las notas como en el grafo.
