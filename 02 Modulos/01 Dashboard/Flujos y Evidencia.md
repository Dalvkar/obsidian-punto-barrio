# Dashboard flujos y evidencia

## Flujo

Abrir panel → consultar agregados → separar ventas de otros ingresos → mostrar alertas y recientes.

## Criterios

- Días sin datos muestran cero.
- Ingreso de ventas y total de caja permanecen separados.
- Stock bajo usa `stock <= minStock`.

## Evidencia

Prueba backend de separación de métricas y prueba UI de indicadores.
